# Police Simulator

پروژهٔ بازی شبیه‌ساز پلیس سه‌بعدی.

## آماده‌سازی ابزارها

راهنمای دریافت ابزارها و وضعیت مجوزها در docs/TOOLCHAIN_AND_LICENSES.fa.md است.
فهرست ساخت‌یافتهٔ ۶۰ ابزار/فناوری در toolchain/manifest.json قرار دارد.

ابزارهای تجاری از طریق حساب و مجوز رسمی ناشر تهیه می‌شوند. installer و کلید لایسنس نرم‌افزارهای اختصاصی داخل Git قرار نمی‌گیرند. دستهٔ آزاد اولیه از طریق GitHub Actions به‌صورت Artifact قابل دریافت است.
