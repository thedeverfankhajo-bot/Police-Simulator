# Police Simulator

پروژهٔ بازی شبیه‌ساز پلیس سه‌بعدی.

## آماده‌سازی ابزارها

راهنمای دریافت ابزارها، وضعیت مجوزها و نتیجهٔ دانلود قبلی در [راهنمای فارسی](docs/TOOLCHAIN_AND_LICENSES.fa.md) است.
فهرست ساخت‌یافتهٔ ۶۰ ابزار/فناوری در [toolchain/manifest.json](toolchain/manifest.json) قرار دارد.

در اجرای GitHub Actions به تاریخ 2026-11-21، شش مورد از هفت installer اولیه با موفقیت دریافت شد؛ نتیجه در [آخرین گزارش](toolchain/last-download-run.json) ثبت شده است.

ابزارهای تجاری از طریق حساب و مجوز رسمی ناشر تهیه می‌شوند. installer و کلید لایسنس نرم‌افزارهای اختصاصی داخل Git قرار نمی‌گیرند.
